# デザインの記録

画面を触るときに毎回ふりだしに戻らないための覚書。決めたこと、試してやめたこと、
その理由を残しておく。トークンの実体は `frontend/src/styles.css` の先頭にある。

## いまの方向：Berry 風の管理画面（左サイドバー + 角丸カード）

機能・ロジックはそのままに、見た目だけを Berry 系の管理画面に寄せた（参考画像に基づく）。
トークンの実体は `frontend/src/styles.css` の先頭にある。

- **骨格**: 左に白いサイドバー（アイコン付きナビ）、上に白いヘッダー、その下に薄いグレーブルー
  （`--panel` `#eef2f6`）の角丸パネル。カードはその上に白で載せる。880px 以下ではサイドバーが
  ドロワーになり、ヘッダーのメニューボタンで開閉する。
- **色**: アクセントはパープル `#5e35b1`、補助にブルー `#1976d2`。現在地（ナビの淡紫ピル）、主操作、
  ダッシュボードのヒーロータイルに使う。グラフは収入＝パープル / 支出＝ブルー（明度差で見分ける）。
- **形**: カードは枠線なし・影 `0 2px 14px`・角丸 12px。入力・ボタンは角丸 8px・高さ 36〜40px。
  バッジは丸いピル。
- **文字**: 本文 14px / 表 13.5px / h1 22px。Inter + JetBrains Mono（数値）は変えない。
- **ヒーロータイル**: ダッシュボード上部に3枚（チーム残高・未精算の立替・精算後見込み残高）。
  値は既存の `summary` から出しているだけで、計算は増やしていない。
- 文字色は白地で ink-2 7.6:1 / ink-muted 4.8:1。色付きタイルの文字は白（紫 8:1 / 青 4.6:1）。

## 試してやめたこと

### 計測用紙と伝票（Timing Sheet & 伝票）

黒帯の精算伝票、チェッカーフラッグ、ヘアラインだけで組んだ角丸なしの帳票、
mono の小見出し（`SPRINT 02` / `JPY`）。レースの世界の語彙を前面に出す方向。

**やめた理由**: 提示したが却下された。振り返ると、ヘアライン + 角丸ゼロ + 密な段組みは
「らしく見える」だけの型で、この画面の仕事（状態が分かる）を助けていなかった。
黒帯やチェッカーは意味を運んでいたが、静かさを犠牲にしていた。

### スコアカード（大きな数値タイルの並び）

各ページ上部に4枚前後のタイルで合計を出す形。**全ページから外した**（依頼による）。
残高や件数は本文の表とスプリント行で読める。上部を占領する価値がない。
`.stat` は残してあるが、使うのはレース管理の1枚だけ。**タイルを足したくなったら、
まず表の中で言えないかを考える。**

## 決めごと

- 数字は必ず等幅 + tabular。金額を縦に並べたときに桁がそろうこと
- 期首 + 収入 − 支出 = 残高 は **演算子を添えて1本の計算として並べる**。
  対等な数字を6つ並べると関係が消える
- 未精算の立替は口座の外の話。罫線で区切って、残高と同じ扱いにしない
- 削除ボタンは常時赤くしない。一覧が赤で埋まると目が削除に向く。触ったときだけ赤くする
- 表は縮めずカードの中で横スクロールさせる（`min-width` を切ると日本語が1文字ずつ折り返る）
- ナビは880px以下で独立した行に移す。560px以下は短縮ラベル
- グラフは月が4か月以下のときだけ棒を太らせる。細い棒が広い帯に点で浮くのを防ぐ
- モーション は hover の 0.1s だけ。`prefers-reduced-motion` を尊重する

## 画面を変えたらやること

1. `npm run build`（型チェック込み）
2. 4画面幅（320 / 390 / 768 / 1280）× 5ページで横あふれとJSエラーを確認
3. 文字色を変えたら白地・淡い地の両方でコントラストを計算し直す
4. 説明書のスクリーンショット14枚とPDFを撮り直す（`docs/README.md` に手順）
